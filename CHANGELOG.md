# Changelog

## 0.1.0 — Initial engineering preview

- Replace the single-turn Ollama CLI with a modular runtime and original HUD.
- Add typed DAG execution, approvals, bounded concurrency/retries, cancellation, durable history, and real result checks.
- Add user-controlled memory, telemetry, schedules, research/coding tools, and optional voice/vision/browser/desktop adapters.
- Add authenticated localhost API, path/network controls, and secret-aware logs.
- Add tests, dependency lock, documentation, native portable packaging, and gated release automation.
- Remove the 18,213 tracked virtual-environment files from the current tree; keep historical commits intact.

This is an early preview with the limitations recorded in `docs/status.md`. No earlier releases, benchmarks, integrations, or hardware tests are invented.
